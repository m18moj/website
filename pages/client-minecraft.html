Minecraft Client

ForgeClient Plugin Manager

Built on: Standalone Java Swing desktop app

A real, compilable desktop application for managing the Bukkit/Spigot/Paper plugin JARs you build from the Minecraft pack’s source files. It lists plugins in your server’s plugins folder, reads their plugin.yml metadata, and lets you enable/disable them with one click. It never connects to or modifies a running server — it only manages files on disk.

Install steps

  1. Install a JDK, version 11 or newer (built and tested against JDK 17).
  2. From the generated-clients/minecraft/ folder, compile: javac -d out src/com/scripforge/pluginmanager/*.java
  3. Run it: java -cp out com.scripforge.pluginmanager.PluginManagerApp
  4. Click "Open Plugins Folder..." and point it at your server’s plugins/ directory.
  5. Compile the pack’s .java scripts into JARs yourself (e.g. with Maven/Gradle against the Spigot/Paper API) and drop them into that folder to manage them here.

Full step-by-step instructions, troubleshooting, and requirements ship in this client's own README.md alongside the code.
