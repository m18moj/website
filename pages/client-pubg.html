About this pack

PUBG Pack is a collection of 28 standalone source scripts covering movement, combat, progression, and UI systems inspired by the genre. Every script is real, working source code with a version number and changelog — not pseudocode.

This client is a preview and organizer, not a mod loader or injector. It lists what's in the pack and links out to the full catalog page and checkout — it never reads from, writes to, or connects to a running game process.

Full pack details, pricing, and the complete script list are on the PUBG pack page.
